# BizLand - Business Website

A modern business website built using HTML, CSS, Bootstrap, and AOS (Animate On Scroll) animations.

## 🛠️ Technologies Used

- HTML5
- CSS3
- AOS (Animate On Scroll)

## ✨ Features

- Modern business website design
- Responsive Bootstrap layout
- Smooth scroll animations using AOS
- Hero section
- About section
- Services section
- Portfolio section
- Team section
- Testimonials section
- Contact section
- Clean and structured UI

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Malini-1326/BizLand-Website.git
cd BizLand-Website
```

### 2. Open the Website

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code.
